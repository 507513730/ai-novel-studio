# 写作工作流

> 规划完成后的逐章生产循环。上下文组装机制详见 [architecture](../architecture.md)。

## 单章生产循环

```
选章 → 生成正文 →（可中止，保留已生成部分）→ AI 审核 → 低分修复（patch_first）
     → 状态回灌（角色/事实/伏笔 → 待确认区）→ 确认入账 → 版本快照
```

- **生成**：流式输出；生成前有成本确认；失败自动恢复生成前内容。
- **审核**：0-100 分 + 问题清单；`needsFix` 由服务端按分数阈值推导（60-74 仅高危才修）。
- **修复**：先局部补丁（原文逐字匹配替换），失败自动降级整章重写，最多 2 轮。
- **回灌**：提取的角色状态/事实/伏笔先进入待确认区，确认后写入账本（跨章连续性）。

## 编辑器能力

- 选区 AI 操作（改写/扩写/缩写/续写）；`Ctrl+J` 光标续写，`Tab` 采纳。
- 字数分离统计：AI 字数与人工字数分别累计（保存时上报）。
- 快捷词：设置页维护 `;触发词 → 展开文本`，编辑器内自动补全。
- 本地校对：确定性检查（重复词/乱码）零 token + 单次语义检查。
- 自动保存：失焦 + 30s 防抖；空内容保护（已有正文不会被空内容覆盖）。

## 版本管理

- 每次生成/修复自动快照；也可手动「存快照」。
- 版本详情 / 与当前 diff / 恢复（恢复前自动再存一版，不丢改动）。

## 整本生产

- 书绑定 whole_book 方案后可一键整本生产（每章走方案步骤接力）。
- 已有正文的章节自动跳过；全部章节失败时任务报 failed（不虚报完成）。
- 任务完成后可自动入队质量债修复（设置页开关）。
