# 备份与恢复

> 数据目录约定：安装版 = 系统用户数据目录；便携版 = exe 同级 `data/`（与 server、备份、清除数据统一）。

## 自动备份

- 每日自动：checkpoint 后复制主库到 `backups/auto-日期时间/`，轮转保留最近 7 份。
- 设置页展示最近备份时间与份数。

## 手动导出

- 「设置 → 导出备份」：选择目标目录 → 应用先请求 server 执行 WAL checkpoint（保证原子）→ 复制主库 + 写入 `backup-info.json`。
- 只导出主库文件（checkpoint 后 wal/shm 为空）。

## 从备份恢复

1. 「设置 → 从备份恢复」选择备份目录（或其中的 db 文件）。
2. 版本不一致时会提示确认（迁移层幂等补齐缺失字段）。
3. 应用自动：停服务 → 替换主库 → 清除旧 wal/shm → 重启服务 → 通知页面刷新。
4. 恢复失败时服务会尝试重启；极端情况手动重启应用即可。

## 升级前快照

应用更新引入数据库迁移前会自动快照（存于用户数据目录），失败可回退——用户运行中的数据库不会被直接修改。

## 清除全部数据

「设置 → 清除数据」：先优雅关闭 server（释放数据库句柄）→ 删除数据目录 → 退出。需要二次确认，不可撤销。
