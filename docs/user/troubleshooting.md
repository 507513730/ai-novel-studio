# 排障指南

> 按症状排查。安全机制相关行为由契约测试锁定（decision-log D116/D118）。

## 生成失败

- **提示「未配置 API Key」**：设置 → 供应商 保存 Key 后重试；模型路由需指向已配置 Key 的供应商。
- **提示「生成被 max_tokens 截断」**：调大该任务路由的 max_tokens 或降低单章字数；被截断的半章不会落库。
- **生成中取消**：点「取消生成」保留已生成部分；章节可重新生成。
- **供应商超时/限流**：应用自动退避并尝试 fallback 候选；全部候选失败才报错。

## 章节卡在「生成中」

- 应用重启会自动将遗留生成中的章节重置为 planned（不重复调用模型）。
- 仍卡住说明另有并发生成（同章不允许双开），等待或重启应用。

## 任务卡住 / 取消无效

- 任务中心可取消排队与运行中任务；运行中任务在章节/阶段边界响应取消。
- 挂死任务 30 分钟无进展会被看门狗回收（日志含 `watchdog:` 前缀），可从任务中心重试（支持换模型）。

## 服务失联（页面提示服务不可用）

- 打包版：server 是独立进程，异常退出后页面会提示；重启应用即可恢复。
- 开发版：检查终端日志与 `AI_NOVEL_PORT`。

## 导出 / 更新

- 导出失败：查看返回的错误信息（多为文件被占用或目录不可写）。
- 更新：安装版支持应用内检查/下载/重启安装；便携版请手动下载（详见 [export-and-update](export-and-update.md)）。

## 数据问题

- 恢复备份 / 清除数据的边界见 [backup-restore](backup-restore.md)。
- 数据库迁移失败：应用会在迁移前自动快照，可回退后重试。
