# 快速上手

> 面向首次使用的创作者。模型配置详见 [model-setup](model-setup.md)，写作流程详见 [writing-workflow](writing-workflow.md)。

## 首次启动

1. 安装版直接运行安装向导；便携版解压后运行 exe（数据保存在 exe 同级 `data/` 目录）。
2. 应用启动后进入「设置 → 供应商」配置 AI 供应商与 API Key（详见 [model-setup](model-setup.md)）。
3. Key 由系统安全存储加密保存，不会明文落库。

## 零决策开写

1. 首页输入一段灵感 → 「导演模式」会自动完成：方向生成 → 项目设定 → 宏观规划 → 世界观 → 角色 → 卷战略 → 节奏板 → 章节清单 → 章节细化。
2. 每个阶段产物落库后可中断/恢复（按产物判定，不会重复调用模型）。
3. 规划完成后进入章节页：选章 → 「✍️ 生成正文」→ 流式生成可随时取消（已生成部分保留）。

## 三个高频入口

- **章节页执行面板**：生成 / AI 审核 / 修复 / 回灌 / 版本快照 / 写作上下文。
- **任务中心**：导演、整本生产等长任务的排队/进度/取消/重试。
- **统计与质量债**：字数分布、成本、审核分、伏笔账本、质量债自动修复。

## 数据在哪

- 安装版：系统用户数据目录（`ai-novel-studio.db`）。
- 便携版：exe 同级 `data/` 目录。
- 每日自动备份保留最近 7 份（设置页可查看/导出/恢复，详见 [backup-restore](backup-restore.md)）。
