# 快速上手（4 步写完第一本书）

本教程带你完成第一次完整创作：配置模型 → 建书 → 生成正文 → 审核修复。全程约 20 分钟（含 AI 生成时间）。

> 面向完全没接触过本应用的新手。想了解实现原理请看 [architecture.md](architecture.md)；想直接看功能清单看根目录 README。

## 第 1 步：安装与配置模型

1. 从 [Releases](https://github.com/507513730/ai-novel-studio/releases/latest) 下载安装版（`AI-Novel-Studio Setup x.x.x.exe`）或便携版（数据跟随 exe，可放 U 盘）
2. 启动应用 → 进入「设置」页
3. 配置模型凭证（二选一）：
   - **OpenCode Go 订阅**：一键「导入 OpenCode Go」——自动读取本机 `~/.local/share/opencode/auth.json`，聚合 DeepSeek/GLM/GPT/Grok/Kimi 等模型
   - **DeepSeek 官方 API**：添加供应商 → 填 API Key + Base URL
4. 点「测试连接」确认绿色 ✓

> Key 经系统密钥环（Windows DPAPI）加密存储，不落明文、不出本机。

## 第 2 步：一句灵感建书

1. 首页（小说列表）→「新建小说」
2. 输入一句灵感，例如：*"失业的程序员在深夜天台捡到一只会说人话的机械鸟，鸟声称自己是十年后的他派来的"*
3. 进入小说工作区，点「自动导演」（选**全自动**）：
   - AI 依次产出：书名方向 → 书级合约 → 宏观 → 世界观 → 角色 → 卷战略 → 节奏板 → 章节清单 → 细化
   - 每个阶段可点开查看/修改，导演进度实时显示（任务中心可换模型重试）

完成后侧栏会出现：方向 / 设定 / 世界观 / 角色 / 卷 / 章节 全部就绪。

## 第 3 步：生成正文与审核修复

1. 进入「章节」页，选一章（未生成状态）
2. 点「AI 生成」——正文流式输出；生成前可输入**本次引导**（如"本章引入反派伏笔"）
3. 生成后点「AI 审核」：评分 + 问题清单（按严重度排序）
4. 点「采纳建议并重写」或「AI 修复」（局部补丁优先，不推倒重来）
5. 满意后「确认状态」——角色状态/伏笔/事实自动回灌全书

常用：
- **反 AI 词重写**：自动替换 AI 腔词汇
- **版本历史**：任何一步都可回退到历史版本
- **30 秒自动保存**：放心离开

## 第 4 步：进阶——方案生产（智能体流水线）

想让每章由"多位智能体接力"写作（大纲 → 描写 → 对话 → 审校 → 合并）：

1. **创造工坊**：新建方案，添加步骤（每步选一个智能体 + 产出类型 outline/draft/scene/dialogue/review/final），或
2. **导入 Feelfish 方案**：创造工坊 → 导入（选 `.feelfish` 目录的 agents/*.md + solution.json），例如 mc-good2.0 十位大师方案
3. 小说设置 → 绑定生产方案
4. 章节页点「以方案生产正文」，或「整本生产」批量逐章走流水线

> 真机验证：mc-good2.0（10 步方案）整章生产 10 步全成功、产出 3000+ 字。

## 之后呢？

- **导出**：章节页/书籍导出 TXT / MD / EPUB
- **资产库**：把好用的设定存为"世界样本/基础角色/写法引擎"，新书一键复用
- **整本生产**：绑定方案后一键批量生成全书的剩余章节
- **任务中心**：随时查看/取消/重试后台任务（导演、整本生产）
