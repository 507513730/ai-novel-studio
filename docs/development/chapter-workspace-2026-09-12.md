# 章节写作页设计与验收（D145）

本批属于 v1.1.3 未发布候选，用户批准章节页设计与实现。正式 tag/Release 单独确认。

## 已实现

- 正文优先三栏布局，章节栏 220px、助手 300px；右侧写作/检查/版本页签有方向键及 Home/End 导航。窄窗口收栏为抽屉，保留专注与阅读入口；字体与主题遵循已有设置。
- 编辑工具栏集中保存状态、阅读、专注、导出。选区 AI 显示原文与结果，返回后先存原章候选版本，采用前检查当前章与请求原文；正文变化时保留结果供手动合并。
- 保存串行、失败不扣字数增量、在途新增输入继续未保存；空正文不能解除离开保护。模型修复遇到已保存正文冲突时保存候选，不覆盖当前稿；重审过期不解除质量债。
- 章节页编排拆为 `useChapterWorkspace`，编辑保存拆为 `useChapterSave`；未新增依赖。D146 新增 v24 保存回执迁移，正文与字数请求统一原文条件检查及操作 ID 去重，版本恢复与恢复前快照在同一事务提交。
- 保存持续确认在途新增输入；加载失败可重试或切章。保存冲突时提供“保存草稿副本并载入最新正文”，先持久化人工稿，操作期间再次输入则保留新输入。版本/候选/AI 结果核对小说、章节与会话生命周期；生成冲突以待采用版本结束，避免低字数重试和旧失败回调破坏新稿。

## 边界

- 已持久化 AI 候选在版本历史可找回；版本写入失败时只暂存当前页面，并显示错误。响应丢失后相同 operationId 的已提交保存可从持久回执重放，不重复增加字数；明确验证失败允许修正正文后新建请求。
- 本批以原文比较实现条件写入，未引入全域单调正文 revision；正文修改后完全恢复原文的 ABA 过程不能仅凭原文识别。浏览器会话 epoch 保护切章返回的迟到响应，不等同于服务端全域版本时钟。
- 本批没有完成所有长任务的取消与重启恢复审查；C1/C3/C4 等仍按原审查计划推进。
- 无模型界面验收不替代正式发布要求的付费 T1-T5 与跨平台安装验证。
